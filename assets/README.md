# Profile artwork

These original SVG illustrations use the Portfolio website's cream, forest-green, ochre, and lilac palette. The cat geometry is shared with William's `Portfolio/src/components/CatIllustration.tsx` so the profile and website use the same character.

- `hello-light.svg` and `hello-dark.svg` form the responsive theme pair in the profile README. The cat greets once and stays still when reduced motion is requested; the dark variant has closed eyes.
- The three project illustrations are conceptual artwork, not product screenshots, live workflow state, medical images, or measured experiment results.
- Assets are self-contained, with no scripts, external fonts, remote images, or generated statistics services. Edit the SVG source directly.
- Project names and purposes are supplied in link text alternatives, with the contribution and technology details in ordinary Markdown below each image.

When revising these assets, check GitHub's rendered profile at desktop and phone widths, in both themes and with reduced motion. Keep image alternatives and the surrounding text useful when images cannot load.
